# Features

One line per feature. Each entry points at the feature's own `specs/features/feature-X/`
folder, where the briefing, roadmap, PRDs and tech specs live.

Features are named two ways:

- **`feature-N`** (a number) — on the plan, being built or already built.
- **`feature-X`** (a letter) — a future candidate that is already prepared: it
  has a briefing, but no commitment to build it yet. When one is picked up it is
  renamed to the next free number.

Status runs 📋 **Planned** → 🛠 **Ready to implement** (every epic specced, no
open questions) → 🔨 **In progress** → ✅ **Done** (every epic implemented,
tested and verified). Lettered candidates sit at ✏️ **Briefed** until promoted.

## Quick changes

Small changes built from a one-page ticket in `specs/quick/` instead of the
five-step chain — `/quick-feature` writes the ticket, asks anything blocking inside it,
and implements it directly. Anything that fails the size test in that skill goes
to `/create-feature` instead.

Status runs 📝 **Drafted** → ❓ **Questions open** → ✅ **Done**.

## Candidate features 

Ideas without a briefing yet, ordered by how directly each serves Sam in
[docs/persona.md](../docs/persona.md): what they play along to and come back
for first, what serves the app's builders last.

| Idea                               | Summary                                                                                                                                                                                                              | Why it's worth it                                                                                                                                                                                                                                                                                             |
|:-----------------------------------|:---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|:--------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| **Preview PRDs**                   | Create a skill that automatically cretes a clickable HTML prototype from a PRD. questions can beanswered in the md file or directly in the prototype                                                                 | Less vibe coding when a feature could already be done (after implement). Get the design ready before writing the tech specs.                                                                                                                                                                                  |
| **Swing jazz ride**                | A ride cymbal for the swung feels — a jazz ride with a light, washy ping, not a rock ride. The kit would hand it the timekeeping and drop the hat to punctuation.                                                    | The groove is the reward Sam plays along to. Tried in feature-13 and removed: MuldjordKit is a rock kit and its ride was far too heavy. The kit has exactly one way of stating a pulse, so the gap is real — it just needs the right cymbal, from a library chosen for it.                                    |
| **Lick variations**                | Have different variations of the licks for the modes.                                                                                                                                                                | "Nothing new tomorrow" is what loses Sam. | **more styles**                    | Blues exception: 12 bars long? Same voice, same voicing code, one extra sample library.                                          | Variety Sam hears the moment the groove starts, without a fourth voice: a second harmony instrument would fight the comp in 55–76 or take the register Sam's sax and guitar play in. The persona says the lead register stays empty.                                                                          |
| **count-in**                       | Optional count-in before the groove starts.                                                                                                                                                                          | Helps find the tempo, and a sax player needs a bar to breathe before the downbeat.                                                                                                                                                                                                                            |
